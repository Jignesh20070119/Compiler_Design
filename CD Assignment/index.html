Why is variable 'y' an Error?

In the primary sample program:

function calculate(a, b) {
    int x = 5;

    {
        int y = x + a;   // <-- 'y' is declared inside this inner block
        float z = y * b;
    }                    // <-- Block Scope Level 2 ends here!

    return x + y;        // <-- ERROR: 'y' is accessed in Function Scope Level 1!
}
Scope Lifetime Analysis:
  1. Scope Level 2 Creation: Variable y is declared inside the nested block { ... } at Block Scope Level 2.
  2. Lifetime Boundary: The scope and visibility of y terminate immediately when the closing brace } of the inner block is executed.
  3. Out of Scope Access: The statement return x + y; is located outside the inner block, in Function Scope Level 1.
  4. Compiler Resolution Result: When resolving y in return x + y;, the compiler searches Function Scope Level 1 and Global Scope Level 0, but fails to find y because its scope has ended.
Suggested Fix: Declare y in the enclosing function scope (Level 1) before the inner block if its value must persist after the block finishes.
